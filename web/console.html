ARD Console

Can AI agents
discover you?

Check any domain: whether its manifest is reachable on all four discovery paths, whether it satisfies the specification, which registries actually return it, and who is returned instead of you for the queries you asked to be found for. Those last two decide whether an agent ever finds you, and nothing else measures them.

Free, no signup. Takes about fifteen seconds.

If the audit found something to fix

You have no manifest

Most domains never write one by hand. If you already run an MCP server, serve an OpenAPI document or publish llms.txt, we can build the manifest from what is already there and host it, and you link it or copy it.

curl -X POST https://neuronto.com/manifest/build \
  -H 'content-type: application/json' \
  -d '{"domain":"example.com"}'

Only resources that actually answered become entries, and each one says what proved it. Nothing is guessed, because a guess would put a claim on your domain that you never made.

You want to prove the domain is yours

Publish one TXT record. The value is derived from your domain and never changes, so asking again never invalidates a record you already published.

curl -X POST https://neuronto.com/claim \
  -H 'content-type: application/json' \
  -d '{"domain":"example.com"}'

We read it over DNS over HTTPS, so it verifies as soon as your zone serves it. Verification is the only thing that issues a key.

You have internal services too

The list of services your own agents may call usually lives in a system prompt, where nothing can search it and nobody can audit it. A verified domain can register them here, and one query then answers across both.

curl -X POST https://neuronto.com/search \
  -H "authorization: Bearer $KEY" \
  -d '{"query":{"text":"look up an employee record"}}'

Private entries are held in separate storage from the public index. No public search, count or page can reach them, and every result says which of the two it came from.
